# Sip & Pill

A friendly offline water & medication tracker built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Full onboarding flow (language, name, tracking mode, water goal, meds, reminders)
- Home dashboard with radial progress and medication checklist
- Settings for notifications, water goals, medications, and data reset
- Persistent local state via `localStorage`

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
